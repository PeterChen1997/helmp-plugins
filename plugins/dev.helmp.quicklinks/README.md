# Quick Search

Type a keyword, a space, then what to search, and Helmp opens the search page in your browser. Complements the web search engines in **Settings › Extensions**.

> Helmp already ships this plugin. This folder is its source and public version: use it as a reference for your own plugins.

## Commands

| Command | Keywords | Opens |
|---|---|---|
| GitHub Repositories | `gh`, `github repo` | github.com repository search |
| npm | `npm` | npmjs.com package search |
| crates.io | `crates`, `crate`, `cargo` | crates.io search |
| MDN Web Docs | `mdn` | developer.mozilla.org search |
| Google Translate | `gt`, `google translate`, `谷歌翻译` | translate.google.com, into the language set in preferences |
| Zhihu | `zhihu`, `知乎` | zhihu.com search |
| Bilibili | `bili`, `bilibili`, `b站`, `哔哩哔哩` | search.bilibili.com |
| Xiaohongshu (RED) | `xhs`, `xiaohongshu`, `rednote`, `小红书` | xiaohongshu.com search |

Example: `npm react`, `gt good morning`.

## Permissions

- Open web pages in your browser

Helmp itself sends nothing over the network; your browser opens the search page.

## Setup

None. Optionally pick the **Google Translate target** language in **Settings › Plugins › Quick Search** (default: Simplified Chinese).

## 简体中文：快捷搜索

输入关键词加空格，再输入要搜的内容，Helmp 会在浏览器里打开对应的搜索页。与「设置 › 扩展 › 网页搜索」互补。

> Helmp 已自带此插件，这里是它的源码与公开版本，可以作为写插件的参考。

### 命令

| 命令 | 关键词 | 打开 |
|---|---|---|
| GitHub 仓库 | `gh`、`github repo` | GitHub 仓库搜索 |
| npm | `npm` | npmjs.com 包搜索 |
| crates.io | `crates`、`crate`、`cargo` | crates.io 搜索 |
| MDN Web Docs | `mdn` | MDN 搜索 |
| 谷歌翻译 | `gt`、`google translate`、`谷歌翻译` | 谷歌翻译，目标语言见偏好设置 |
| 知乎 | `zhihu`、`知乎` | 知乎搜索 |
| B 站 | `bili`、`bilibili`、`b站`、`哔哩哔哩` | B 站搜索 |
| 小红书 | `xhs`、`xiaohongshu`、`rednote`、`小红书` | 小红书搜索 |

例：`npm react`、`gt 早上好`。

### 权限

- 在浏览器中打开网页

Helmp 自己不发网络请求，只是让浏览器打开搜索页。

### 配置

不需要。可以在「设置 › 插件 › 快捷搜索」里选「谷歌翻译目标语言」（默认简体中文）。
